# 1) VM
- Deploy a VM in Azure with a specific VM Size, OS, and Region

# 2) Custom RBAC Role Assignment
- Create an Entra ID User
- Assign them a Custom RBAC Role, Scoped directly to the Specific VM

# 3) Azure Policy
- Create an Azure Policy Assignment that enforces a Tagging requirement on all resources within RG

# 4) Disk Encryption
- Configure encryption on VM using Azure Disk Encryption

# 5) Cost Management Alert
- Set up a Cost Alert (budget alert), config'd to trigger at a specific Spend Threshold
